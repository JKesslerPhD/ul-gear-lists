# ul-gear-lists

What are ultralight backpackers actually carrying? An anonymized database of 345 public LighterPack lists from r/Ultralight users who keep a LighterPack link in their user flair, plus the code that identifies each list's pack, shelter, quilt and sleeping pad and turns the lists into the numbers behind the post [What Gear Are Ultralight Backpackers Using?](https://trailpeaches.com/?p=2561).

Everything is standard-library Python 3 and SQLite. No dependencies.

## What is in here

| Path | What |
|---|---|
| `data/ul_flair_lists.db` | The database: 345 lists, 3,192 categories, 20,606 items. Usernames, list URLs, list names and post metadata are removed. See [DATA.md](DATA.md). |
| `ulgear/classifier.py` | Finds the pack, shelter, quilt/bag and pad in each list. See [METHODS.md](METHODS.md). |
| `ulgear/text.py` | Name + description normalization shared by the scripts. |
| `analysis/report.py` | Base-weight summary, the Big 4, frequency and weight of ~55 item "slots", the median gear list. |
| `analysis/modal_kit.py` | The modal kit and the top 5 products per category. |
| `analysis/cohort_check.py` | Compares the two ways the users were found. |
| `tests/` | Regression test against the hand-checked classifier picks. |

## Run it

```bash
python3 analysis/report.py        # writes out/report.txt, out/item_frequency.csv, out/median_gearlist.csv, out/slot_models.json
python3 analysis/modal_kit.py     # writes out/modal_kit.csv, out/top5_by_category.csv
python3 analysis/cohort_check.py
python3 tests/test_classifier.py
python3 -m ulgear.classifier --misses     # lists where a role was not found
python3 -m ulgear.classifier --show 17    # all items of list 17 with the role each got
```

Query the database directly:

```sql
-- median base weight
SELECT base_weight_g FROM lists ORDER BY base_weight_g LIMIT 1 OFFSET (SELECT COUNT(*) / 2 FROM lists);

-- the quilt in every list
SELECT l.id, i.name, i.total_g FROM items i JOIN lists l ON l.id = i.list_id WHERE i.core_role = 'quilt';
```

## Caveats

- Everyone here chose to put a list in their flair. This is people who like their lists read, not a random sample of backpackers.
- Roughly 18% of items have no weight entered. Slot weights come from the items that do.
- Items are identified from names and descriptions. Many are named generically ("Backpack", "Quilt"), so brand shares are floors.
- Base weight is total minus the items the owner flagged worn or consumable, so it inherits the owner's flags.

## AI and data disclosure

Generative AI was used to help write most of the code in this repository, and a large language model read the lists where the rule-based classifier missed a pack, shelter, quilt or pad; those reads were used to refine the rules, and every pick in the database comes from the classifier itself. The data are real public LighterPack lists and were not generated by an LLM. Results are calculated directly by the code from the fixed data set, so they are not subject to hallucination and are repeatable. Accuracy depends on the underlying lists and the classification rules.
